# Contributing to AIP-HSD

We welcome contributions to the AI-Powered Hybrid Security Dashboard!

## 🛠️ Polyglot Contribution Guidelines
- **Core Backends**: Python (FastAPI), Node.js, Go, or Rust.
- **Frontends**: React-TS, Next.js, or Static HTML.
- **Specialized Modules**: We accept PRs in any of our 30+ supported languages.
- **Testing**: Every PR must include a test script compatible with the Universal Test Runner (\`scripts/test_all.py\`).

## 🚀 Getting Started
1. Fork the repository.
2. Create a feature branch.
3. Commit your changes with a clear description of the language stack used.
4. Open a Pull Request for review.
