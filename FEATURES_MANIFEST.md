- **K - KPI Tracking:** Real-time monitoring of Global/Internal Threat Levels, Network Health, and Alert Trends.
- **L - Local LLM Integration:** Supports GGUF and GPT-2 style models for on-premise summarization and query handling.

- **S - Security & RBAC:** Secure access via JWT authentication and granular Role-Based Access Control.
- **T - Tactical UI Components:** Glassmorphic Risk Cards, Live Alerts Feed, and AI Insights Panels.
- **U - Unified Data Schema:** Normalization logic that converts disparate log formats into a single analysis-ready schema.

- **W - WebSocket Alerts:** Real-time push notification system for immediate delivery of critical alerts.
- **X - X-Platform Binaries:** Native executables for Windows (.exe), Linux (.bin), macOS (.app), and ARM architectures.

- **Z - Zero-Radius Design:** A clinical, high-precision aesthetic with sharp edges and minimal visual clutter.

## ⚙️ Functions & Logic

### 1. AI Correlation Engine
- **Logic:** Matches internal `port` and `keyword` anomalies with global `threat` descriptions.
- **Output:** `CORRELATED_THREAT` objects with confidence scores and recommended actions.

### 2. Risk Calculation
- **Algorithm:** `Score = min(100, (Sum(Threat_Severity) * Weight) + (Internal_Anomaly_Count * Factor))`.
- **Normalization:** All scores are rounded to 2 decimal places and categorized into risk bands.

### 3. OSINT Pipeline
- **Fetch:** Aggregates data from RSS (e.g., US-CERT), Scrapers (e.g., BleepingComputer), and Web Search.
- **Filter:** Deduplicates and tags intelligence based on relevancy to internal infrastructure.

## 🛠 Settings & Configuration

### Backend Settings (`backend/app/core/config.py`)
- `DATABASE_URL`: PostgreSQL connection string.
- `REDIS_URL`: Redis connection string for caching/tasks.
- `SECRET_KEY`: Security key for JWT token generation.
- `ACCESS_TOKEN_EXPIRE_MINUTES`: Session duration setting.

### AI Model Settings (`ai_module/analyzer.py`)
- `MODEL_NAME`: The identifier for the local LLM (e.g., "AIP-GPT-2").
- `THREAT_TACTICS`: Mapping of threat types to specific remediation actions and priorities.

### Agent Configuration (`agents/collector.py`)
- `SERVER_URL`: The backend API endpoint for telemetry reporting.
- `SCAN_INTERVAL`: Frequency of system scans (default: 60 seconds).
